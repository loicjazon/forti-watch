# forti-watch macOS — plan d'implémentation

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** publier forti-watch pour macOS (binaire universel) en plus de Linux, avec la même logique de session.

**Architecture:** un seul crate ; couche plateforme `src/linux/` (GTK, inchangée) et `src/macos/` (AppKit via objc2)
choisie par `#[cfg(target_os)]` ; source VPN par OS (`forticlient-cli` / `scutil --nc`) ; parseurs purs compilés et
testés partout.

**Tech Stack:** Rust 2024, gtk 0.18 + libappindicator (Linux), objc2 0.6 / objc2-foundation 0.3 / objc2-app-kit 0.3 /
block2 0.6 / libc 0.2 (macOS), POSIX sh, GitHub Actions.

**Spec:** `docs/superpowers/specs/2026-10-16-macos-design.md`

## Global Constraints

- Code, commentaires, messages, docs en français ; noms de variables ≥ 3 caractères.
- Tests Arrange / Act / Assert, un comportement par test, pas d'horloge réelle (`now` en paramètre).
- Aucune donnée réelle dans le dépôt (nom d'entreprise, domaine, IP, UUID de service, jeton).
- `cargo clippy --all-targets -- -D warnings` propre sur Linux **et** macOS ; `cargo fmt --check`.
- Commits : gitmoji + Conventional Commits en français, ≤ 72 caractères, trailer Co-Authored-By.
- Premier commit de code = refacto Linux sans changement de comportement.
- Assets : `forti-watch-linux-x86_64`, `forti-watch-macos-universal` (+ `.sha256`) ; version 1.3.0.
- Jamais de sortie brute de `scutil` dans un message (elle contient le jeton de session).

## Review Focus

- `Connected` sans `LastStatusChangeTime` lisible → `Err` (état inconnu), pas « déconnecté » (Tâche 2).
- Plusieurs services VPN dans `scutil --nc list` → seul celui de FortiClient est retenu (Tâche 2).
- `LastStatusChangeTime` dans le futur (horloge recalée) → `elapsed = 0`, pas de panique (Tâche 3).
- Erreur de lecture → message sans la sortie brute (pas de jeton) (Tâche 3).
- `Reasserting` → session gardée (`Err`) (Tâche 2).
